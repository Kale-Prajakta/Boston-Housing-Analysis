Week 2 : Assignment

# 🏡 Supervised Learning: Regression & Classification

This project applies **Linear Regression** and **Logistic Regression** on the **Boston Housing dataset** to predict housing prices and classify homes as high or low value. It includes model evaluation and visualizations using `matplotlib`.

---

## 📁 Dataset

- File: `HousingData.csv`
- Source: [Boston Housing Dataset on Kaggle](https://www.kaggle.com/datasets)
- Target variables:
  - `MEDV` — Median value of owner-occupied homes (regression)
  - `HighPrice` — Binary label based on median `MEDV` (classification)

---

## 🎯 Objectives

- Predict house prices using Linear Regression  
- Classify homes as High or Low priced using Logistic Regression  
- Evaluate models using standard metrics  
- Visualize model performance with plots and confusion matrix

---

## 🛠️ Tech Stack

- Python  
- Pandas, NumPy  
- Scikit-learn  
- Matplotlib

---

## 📊 Evaluation Metrics

### Regression
- RMSE  
- R² Score  

### Classification
- Accuracy  
- Precision  
- Recall  
- F1 Score  

---

## 📈 Visuals

- Scatter Plot (Actual vs Predicted)
- Residual Plot
- Confusion Matrix
